Each card shows one rule of Ruby's Ractors as a short loop: a Ractor is a room, a port is a mailbox on its wall, a message is an envelope, and a thread is a dot. The rule is a step in a TLA+ model, and the TLC model checker visited every state the bounded model can reach. A Ruby harness then replayed every transition on CRuby, and every replay passed.

Hover a card to see its restart button. A grey tag shows what the Ruby documentation says about the rule.
